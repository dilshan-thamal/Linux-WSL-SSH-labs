# Evidence collection

Add evidence only after performing each step. No screenshots or SSH connection results have been recorded yet.

Use descriptive filenames and annotate what each screenshot or text output demonstrates. Keep the full diagnostic sequence in the relevant case report.

Exclude passwords, private keys, tokens, personal information and unrelated workplace details. Keep unsanitised captures in `evidence/raw/` (ignored by Git). Review all files before committing; .gitignore does not remove files already tracked.
